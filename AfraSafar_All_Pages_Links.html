نقشه تمام صفحات افرا سفر

۶۶ صفحه HTML از آخرین بسته کامل پروژه، دسته‌بندی‌شده و قابل جست‌وجو. لینک‌ها برای Live Server روی رایانه خودت هستند و لینک عمومی اینترنتی محسوب نمی‌شوند.

اگر در VS Code پوشه بیرونی را با Live Server اجرا کرده‌ای، آدرس پایه را به http://127.0.0.1:5500/afra-safar/ تغییر بده. صفحات مدیریتی نیاز به مجوز و ورود مناسب دارند. صفحات آزمایشی یا کپی لزوماً جزو مسیر اصلی کاربران نیستند.
