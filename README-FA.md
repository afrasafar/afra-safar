# افرا سفر — اتصال خودکار تلگرام مسافر

برای مراحل نصب و راه‌اندازی قابلیت اتصال تلگرام مسافر، فایل `README-FA-TELEGRAM-AUTO.md` را بخوان.

فایل‌های SQL را به ترتیب راهنما اجرا کن: ابتدا `supabase-telegram-link-migration.sql`، سپس پس از آماده‌کردن Router در Make، فایل `supabase-telegram-confirmation-trigger.sql`.

**مهم:** تا وقتی مسافر روی لینک تلگرام رزرو کلیک نکند و در ربات `Start` را نزند، ربات اجازه ندارد خودش اولین پیام خصوصی را برای او بفرستد.
