# اتصال تلگرام مسافر به رزرو افرا سفر

این بسته قابلیت لینک‌کردن یک گفت‌وگوی تلگرام به یک رزرو و آماده‌سازی مسیر اعلان تأیید را اضافه می‌کند. نام ربات: **@AfraSafarReserveBot**.

## مهم
- ارسال خودکار فقط پس از یک بار فشردن Start در ربات توسط خود مسافر امکان‌پذیر است. تلگرام اجازه نمی‌دهد ربات صرفاً با داشتن شماره موبایل، گفت‌وگوی خصوصی را شروع کند.
- اتصال live به Supabase و Make از این محیط ممکن نیست. برای نهایی شدن، مراحل SQL و Make زیر را انجام بده.
- از توکن ربات در فایل سایت استفاده نکن؛ توکن فقط در Connection امن Make باشد.

## مرحله ۱ — SQL برای اتصال مسافر
1. Supabase → SQL Editor → New query.
2. محتوای `supabase-telegram-link-migration.sql` را کامل اجرا کن. این فایل ستون‌های توکن/شناسه تلگرام و دو تابع RPC را اضافه می‌کند؛ منطق رزرو و پرداخت را تغییر نمی‌دهد.
3. فایل‌های سایت را از این بسته جایگزین کن. بعد از ثبت رزرو یا در صفحه پیگیری، لینک «اتصال تلگرام به این رزرو» نمایش داده می‌شود.

## مرحله ۲ — سناریوی Make برای اتصال تلگرام
یک سناریوی جدید بساز؛ سناریوی اعلان رزرو فعلی را فعلاً تغییر نده.

1. ماژول اول: **Telegram Bot → Watch Updates**. Connection را `AfraSafar Telegram` انتخاب کن. اگر فقط `AfraSafar Telegram Test` داری و همان ربات را وصل کرده، همان را انتخاب کن. Webhook را بساز و ذخیره کن.
2. بعد از ماژول، فیلتر بگذار که `Message: Text` با `/start ` (اسلش start و یک فاصله) شروع شود.
3. ماژول بعدی: **HTTP → Make a request**. تنظیمات:
   - Method: `POST`
   - URL: `https://chrdvpwympsskclbvnsz.supabase.co/rest/v1/rpc/link_reservation_telegram`
   - Body type: JSON / application/json
   - Headers:
     - `apikey`: مقدار `SUPABASE_PUBLISHABLE_KEY` از فایل `supabase.js`
     - `Authorization`: `Bearer ` به‌اضافه همان مقدار publishable key
     - `Content-Type`: `application/json`
   - Body باید دو فیلد داشته باشد: `p_token` و `p_chat_id`. برای `p_token`، از خروجی Message: Text، مقدار بعد از `/start ` را قرار بده (در Make می‌توانی از تابع `replace` استفاده کنی: `replace(Message: Text; "/start "; "")`). برای `p_chat_id`، مقدار `Message: Chat: ID` را انتخاب کن. متغیرها را از پنل Make انتخاب کن، نه اینکه نام آن‌ها را به صورت متن ثابت وارد کنی.
4. بعد از HTTP، روی خروجی JSON آن فیلتر بگذار که `success` برابر `true` باشد. سپس **Telegram Bot → Send a Text Message or a Reply** اضافه کن:
   - Chat ID: `Message: Chat: ID` از ماژول Watch Updates
   - Text: `✅ تلگرام شما به رزرو افرا سفر متصل شد. پس از تأیید میزبان، اطلاعات رزرو و پرداخت در همین ربات ارسال می‌شود.`
5. سناریو را ذخیره و روشن کن. از سایت یک رزرو آزمایشی بساز، لینک اتصال را بزن و در ربات Start را بزن. باید پیام تأیید اتصال دریافت کنی.

## مرحله ۳ — شاخه تأیید در سناریوی فعلی رزرو
این مرحله را قبل از اجرای فایل SQL دوم انجام بده تا پیام مدیر دوباره‌کاری نشود.

1. سناریوی فعلی که با Webhook از Supabase شروع می‌شود و پیام رزرو را برای مدیر می‌فرستد باز کن.
2. بعد از Webhook یک **Router** قرار بده. شاخه اول فقط برای `type = INSERT` باشد و مسیر فعلی اطلاع‌رسانی مدیر را نگه دارد.
3. شاخه دوم را با فیلترهای `type = UPDATE`، `record.status = confirmed` و `record.telegram_chat_id` غیرخالی تنظیم کن.
4. در شاخه دوم یک ماژول **Telegram Bot → Send a Text Message or a Reply** اضافه کن. Chat ID را از `record.telegram_chat_id` انتخاب کن. متن پیام را از فیلدهای `record` بساز؛ نام مهمان، کد رزرو، شماره تلفن، تاریخ‌ها، تعداد نفرات، `payment_base_amount`، `discount_percent`، `discount_amount`، `payment_amount` و `payment_deadline_at` باید از رکورد UPDATE بیایند. برای نام اقامتگاه و موقعیت، همان ماژول lookup اقامتگاه را که در مسیر فعلی پیام رزرو استفاده می‌کنی، برای `record.property_id` هم اجرا/کپی کن. شماره کارت ثابت است: `6219861924453805` به نام `محمد رسولی`.
5. در متن، توضیح بده که پرداخت ظرف ۲۰ دقیقه انجام شود و رسید در همین ربات فرستاده شود.
6. ذخیره کن و بدون فعال‌کردن trigger جدید، اگر امکانش هست مسیرها را با نمونه داده آزمایش کن.

## مرحله ۴ — فعال‌کردن اعلان پس از تأیید
بعد از آماده بودن دو سناریوی Make و شاخه UPDATE، فایل `supabase-telegram-confirmation-trigger.sql` را در SQL Editor اجرا کن. این trigger همان Make webhook فعلی را برای رخداد UPDATE صدا می‌زند و فقط زمانی اجرا می‌شود که رزرو تأیید شده و chat ID متصل باشد. اگر مسافر بعد از تأیید متصل شود نیز اعلان به‌واسطه تغییر `telegram_chat_id` اجرا می‌شود.

## محدودیت فعلی
در متن اعلان داخل Make باید فیلدهای مناسب را با پنل Map انتخاب کنی؛ ساختار bundle دقیق در هر سناریو متفاوت است. این بسته خودش به Make شما دسترسی ندارد و نمی‌تواند mapping/فعال‌بودن سناریو را از اینجا تأیید کند. هرگز Bot Token را در سایت یا فایل‌های عمومی قرار نده.
